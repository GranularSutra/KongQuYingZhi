### 模板获取

方式方法：让AI自己生成，然后自己分析套用了哪个模板，这相当于让AI在"写八股文"的同时，自己当考官把文章结构拆给你看。


### 实现路径

#### 第一步：让AI生成赏析/评价文本
用现有的拐杖方案（提示词+RAG）生成一段"苹果公司评价"。

#### 第二步：用你的V2反向解析这段文本
```python
# 输入刚才生成的评价文本
text = "苹果公司由乔布斯创立于1976年。该公司以创新设计著称。同时，其封闭生态也引发争议..."

# HanLP解析
parsed = HanLP.parse(text)

# 提取结构
骨架1: "苹果公司→创立→1976年" → 标签：背景
骨架2: "公司→著称→创新设计" → 标签：正面评价
骨架3: "生态→引发→争议" → 标签：负面评价
```

#### 第三步：输出模板识别结果
```json
{
  "识别到的模板": "评价类模板V2",
  "结构": [
    {"段落1": "背景介绍", "骨架": "实体+创立+时间"},
    {"段落2": "正面评价", "骨架": "实体+优点"},
    {"段落3": "负面评价", "骨架": "实体+缺点/争议"},
    {"段落4": "总结", "骨架": "总体+综合判断"}
  ],
  "置信度": "92%",
  "套用模板来源": "标准评价类模板库 v1.3"
}
```

---

### 这个功能有什么用？
- 自我修正：如果AI发现套用的模板不对，可以自动重新生成 |
- 模板库挖掘：分析大量AI生成文本，反推出高频模板结构，扩充你的模板库 |
- 风格分析：对比不同AI的模板偏好（比如某模型总是先扬后抑） |
- 人工审核辅助：快速判断一段文本是否模板化，以及模板来源 |
