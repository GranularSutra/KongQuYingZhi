
#### 适配场合
UTF-8文本分词/理解
特征：分词 →句法/词法/字法 →语义，三位一体。
特征：人交流，其整句，本就无需完整主谓宾。强行对齐人编的共识，是反智行为。
	“FUCK！”“你滚！”“来啊！”“真美。”“下雨了。”“Hi”
	问“你哪的？”，答“淮阴工学院”
错误表述举例：名词作谓语
正确表述举例：名词成句
词性举例：跑跳是累人的。（凡指代，皆名词)

#### 专名标记
一个词是专名还是普通名词，由它所在的句子位置决定，不由词表决定。
特征：主/宾语高频；名词堆叠；VV，比如”推敲“就是典故专名，理应“查表可得”

几类举例：
修饰+核心  →  “测验魔石碑” →  xxx碑 → 整体为专名（物名）
姓氏+名  →  “萧炎” 整体为人名
名词+机构  →  加玛帝国，江阴市，中医院，河海大学，迦南学院，云岚宗，中科院，派出所，社保局
名词+物件  →  异火榜，魂殿，丹塔
名词+集体代词   →  萧家，北大，沈氏，古族，炊事班，后期组，突击队，文工团
名词+名词   →  律师/法师/教师/灯光师/理发师（行业/领域 + 师=职业），李师/张工/吕导/王总/刘博（姓+职=称呼）


#### 实体识别例举

识别顺序：词典 → 切分 → 句法（先动词，然后元素/结构） → 名词 → 高频统计or模式匹配 → 专名锁定

通用模式：[修饰名词] + [核心名词] → 整体名词
	地名 + 集体后缀 → 家/族/氏	萧家、古族、沈氏
	地名 + 机构后缀 → 校/院/局	北大、河海大学、民政局
	行业 + 职称后缀 → 师/家/员	律师、作家、程序员
	姓氏 + 职称简称 → 工/导/总	张工、吕导、王总
	修饰 + 碑/塔/殿/榜 → 测验魔石碑、丹塔、魂殿、异火榜

规则 A：规则 A：名词 + 集体代词 → 集体专名
	规则：名词（姓氏/地名/领域名/修饰语） + 集体后缀（表“一群人/一个组织”）  → 集体/组织专名
	家族/血缘类
		家、族、氏、门、姓、宗                                
		例：萧家、古族、沈氏、龙门、张姓、少林宗 
	机构/单位类
		校、院、所、局、处、科、室、部、厅、署、站、台、社
		例：北大（大学省称）、中科院、派出所、社保局 
	团队/班组类
		班、组、队、团、连、营、排、伍、帮、派、会、盟 
		例：炊事班、后期组、突击队、文工团、少年帮、丐派、商会 
	行业/圈子类
		界、圈、行、坛 
		例：教育界、娱乐圈、金融行、文坛  

规则B：名词 + 名词 → 职业/称呼（限定性组合）
	规则B1：行业/领域（法学、心理、理发、编程） + 职称后缀（师、家、员、手、匠） → 职业身份
		例：律师、法师、教师、灯光师、理发师、作家、演员、程序员、投手、画匠
	规则B2：姓氏 + 职称简称（师、工、导、总、博、老、局、处、所、科、院） → 社交称呼
		例：李师、张工、吕导、王总、刘博、陈老、周小  
	处理动作
		B1：锁定为“职业名词”，带行业标签
		B2：锁定为“社交称呼”，带关系/层级标签
		两者均跳过普通词法解析

规则C：地理通名后缀（山/河/湖/海/城/镇/村/省/市/县/路/街/巷/楼/塔/殿） + 修饰语 → 地理专名
	例：泰山、黄河、西湖、上海城、乌坦镇、萧家村、青云省、乌坦城、帝都路、魂塔、丹殿

规则D：修饰语 + 器物/文件后缀（碑/榜/卷/典/经/法/诀/录/册） → 文化专名
	例：测验魔石碑、异火榜、焚决、玄阶斗技、丹方、功法卷轴

#### 词典格式

```
词  频次档位  词性1  词性2(可选)
水神流  3  n
姜梨  3  n
把  3  f
被  3  f
的  3  f
啊  1  f
```

固定顺序：词 → 频次档位 → 词性。 不用猜位置，每列对齐。

#### 词性列表（粗分=2bit，细分=8bit）
分类：名动形虚

- 名n:一切可被指代的，包括事物、概念、存在、事件（主语/宾语）
	存在：
		实体：具体物质、物体（水、剑、丹药、魔石碑）、生命
		抽象：概念、性质、状态名词化（自嘲、疼痛、嘲讽、面子）
		事件：由动词派生的事件（测验、战斗、晋升）
		时空：时间点/段、空间位置（三年前、广场、掌心、家族、背面、上面、左边、右角）
		代词（我、你、他、她、它、这、那、其、自己）（等效名词）
	关系：父亲、族长、对手、同伴
	量度：单位（kg、kw、$）、等级、数值（三段、九级、一抹、一根根、个、条、个、条、张、段）
语法：作为主语、宾语，或者独立成句。

- 动v:动作，谓语核心
	判断：是、乃、为
	变化：成为，变得
	使令：让，使得，导致，惹得，令
	意愿：想要、希望、愿意
	存现：有（have），露出，遮蔽，隐瞒，出现，消失（appear），带起，引发
	感知：看，望，听，觉，以为
	言说：知，道，说，晓，嘲讽，公布
	位动：来、去、起、出、回
	其他：拿起、刺进、公布、丢光、转身、抬头、对待、等待、落下
语法：后验的特征和规律，把符合主谓宾模式的谓语，都叫做“动词”，包括其变体“系动词”

- 形a:一切修饰功能词，无论修饰名词、动词还是形容词
	形容词：属性、性质、程度、评价（漂亮、高、灵巧、刺眼、苦涩、狼狈）（修饰语）
		属性：清秀、稚嫩、漆黑、尖锐
		状态：苦涩、急促、漠然、落寞
		评价：刻薄、势力、丢脸、狼狈
		程度：深深、狠狠、微微、缓缓
		数量：序数（最后、第一），大致量（许多、一些、都、部分），填充率（充盈）
		比拟：耀眼、刺眼
举例：爱得深沉；深沉的人；漂亮女孩；她很漂亮；
	
- 虚f:功能词（程度/范围/否定/时体/结构/语气/介词/连词）（句法骨架）
	结构助词：（定中、状中、补语标记）；的、地、得
			代词+的+名词
			修饰词+地/的+动词，比如”麻木的搬运“
			主语（可能隐藏）+  修饰词 + 地/的 + 动词 + 宾语）
			动词+得+程度
			（的/地，实际很少分写，故合并）
			（的/地/得，经常被全写为”的“
	时体助词：（过去/进行/完成/将来）；了、着、过、将
	时空介词：（时空关系）；在、到、从、向、于、里、上、内
	动词提示：把、被、将、用
	依据介词：（依据/方式/比较）；按照、根据、比、如
	因果连词：（因果/目的/条件）；因为、所以、之所以、为了
	逻辑连词：（并列/转折/递进/让步）；和、但、不但…反而、虽然、和、与、或
	逻辑副词：（判断/程度/概率）；明确的逻辑判断（不、非、也、还、最、必），概率（也许、果然），程度（太，过，乏，足，够）
	时间副词：（时间锚定）；刚刚、曾经、如今、早已
	情态副词：（方式/语气/频度）；竟然、忽然、往往、又
	语气词：（疑问/感叹/揣测/强调）；吗、呢、啊、吧、了（句尾）
	标点/停顿：（分割/语气/引用）；， 。 ！ ？ … “ ”
	时序连词：（顺序/承接）；于是、然后、接着、逐渐，瞬间，马上，立刻

#### 频次档位（2bit）

档位0：低频
档位1：中低频
档位2：中频
档位3：高频

#### 存储体积
词本体：（UTF-8）不定（按需）
频次档位：2bit
词性1：4bit
词性2（可选）：4bit 
总计=10bit（约2字节）


#### 为什么这样更干净

1. 顺序固定：读一行就知道第0列是词，第1列是频次档位，第2列起是词性
2. 不需要专名标记：专名就是名词，不需要单独分类
3. 功能词，在表达引擎/理解模块中可以单独细化，而非立即复杂。比如“被动标记”。


#### 标注举例1
输入+分词：[中年男子] [话] [刚刚] [脱口] ，[便是] [不出意外] [在] [人头汹涌] [广场] [上] [带起] [了] [一阵] [嘲讽] [骚动] 。


#### 标注举例2
输入：人不风流枉少年

Step 1 词典：查“人”“不”“风流”“少年”均在词典 → 保留候选；“枉”在词典中标注为【动·省缩】→ 高优先级候选
Step 2 切分：候选序列 [人][不][风流][枉][少年] 为最优（因“枉”强制为动词）
Step 3 句法（先动词）：“枉”为谓语核心 → 左查主语“人”→ 右查宾语“少年”→ 发现“不风流”修饰“枉”的条件
Step 4 名词：“人”为主语 → 标【名·实体】；“少年”为宾语 → 标【名·实体】
Step 5 高频统计：无需启动，已全部解析
Step 6 专名锁定：未发现专名 → 无动作

输出：
人 [名·主语]
不 [虚·否定]
风流 [形·修饰]
枉 [动·谓语]
少年 [名·宾语]
