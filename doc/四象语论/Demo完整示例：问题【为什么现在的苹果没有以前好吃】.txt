## 0. 设计原则（写死）

1. 首搜键 = 核心实体；时间词、否定词等限定词（包括修饰、形容），不作。限定词默认作二道筛选。
2. 关键词 ↔ 词条多对多：一个关键词挂若干词条，一条词条被若干关键词索引。
3. 词条是原子属性条目，一属性一条。
4. 多义词按用度筛领域（如"打蜡"分食品/工业/皮革，按问句取一组）。
5. 词条分层：`S` 学科层（相对可靠可引用）；`W` 互联网语料层（真假混杂，仅线索/交叉，标"待验证"）。物理分区，分开引用。
6. 求交 = posting list 交集，不拼路径；短 posting 先交。
7. 空集降级 = 按品类放宽：具体型号/年份搜不到，退到其所属品类再搜（华为B8888搜不到→按"手机"搜）。
8. 增改即时生效 = 加词条 + 补倒排索引条目，两者缺一不可；无训练。
9. 输出全部溯源条目 ID + 层级标记，不编造。

## 三、模拟验证（逐用例）

### 用例 1：苹果问句（无年份，时间不作键）

输入：为什么现在的苹果没有以前好吃
首搜：`苹果` → 全 posting。
读语义：前提"以前好/现在不好"，任务=解释差异；问句无年份→不挑年份、时间不作键。
用度筛：打蜡取食品组 S-W01~W04，工业/皮革 S-W05/S-W06 不选。
分层交叉：S 给机理（S-W01/W03、S-C02、S-C03、S-C01、S-A03、S-F01）；W 给线索（W-01/W-02/W-03）交叉印证。
输出：
> 现在苹果不如以前好吃，可能原因：
①流通打蜡变化：早年本地短途基本不打蜡，近年长途冷链普遍打食用蜡(S-C01)，果蜡封气孔抑果香、风味衰减(S-W01/S-W03)，虽延长货架(S-W02)〔学科层〕；
②采摘与品种：现代提前采摘、品种选育优先耐储运外观，风味优先级降低(S-C02/S-C03)〔学科层〕；
③好吃是果香/糖酸比/口感综合主观感受(S-A03/S-F01)〔学科层〕；
④网络反馈：消费者称"没以前香、皮油"、果农科普提提前采摘冷库影响、品种换代口感变化——与机理一致，待验证〔W-01/W-02/W-03〕。

---

### 用例 2：多约束求交唯一落点（时间作筛子启用）

输入：2014年的A市B司股价
约束 token：`2014年`、`A市`、`B司`、`股价`
- `2014年` → {T-2014股价, T-2014营收}（2）
- `股价` → {T-2014股价, T-2020股价, S-B03}（3）
- `A市` → 6条；`B司` → 5条
求交（短先）：`2014年`∩`股价`={T-2014股价}；∩`B司`={T-2014股价}；∩`A市`={T-2014股价}
唯一命中：T-2014股价
输出：2014年A市B司股价年均 12.4 元，区间 9~16 元(T-2014股价；A市见S-B01，B司见S-B02)。
> `2014年`与`2020年` posting 不重叠，天然落 2014，不串 2020。

### 用例 3：对比双时间各求交

输入：2020年A市B司股价比2014年高吗
分支2020：`2020年`∩`A市`∩`B司`∩`股价`={T-2020股价}
分支2014：`2014年`∩`A市`∩`B司`∩`股价`={T-2014股价}
输出：2014 年均 12.4 元(T-2014股价)，2020 年均 28.7 元(T-2020股价)，2020 高于 2014。对比由两分支数值直接得出，无关系规则表。

### 用例 4：同实体不同维度不串

输入：2020年A市B司营收
求交：`2020年`∩`营收`={T-2020营收}；∩`B司`；∩`A市` → {T-2020营收}
输出：2020年A市B司营收约 210 亿元(T-2020营收)。`股价` posting 不带出营收条目，维度不串。

### 用例 5：空集降级 = 按品类放宽（你口述的华为B8888）

输入：华为B8888这个手机为什么垃圾老是卡顿呢
约束 token：`华为B8888`、`手机`、`卡顿`、`垃圾`
- `华为B8888` → 无此倒排键（型号瞎编）→ 空 token
- `手机` → {S-P01,S-P02,S-P03,W-05}
- `卡顿` → {S-P01,S-P02,W-05}
降级：型号搜不到→按品类"手机"放宽（记录：放宽 `华为B8888`，退到品类`手机`）
求交：`手机`∩`卡顿` = {S-P01,S-P02,W-05}
输出：
	未找到"华为B8888"该型号词条（降级记录：放宽型号，按品类"手机"检索）。
	手机卡顿常见原因：内存不足、存储将满、后台过多、系统老旧、电池老化降频、散热差(S-P01)；
	排查：清理存储后台、更新系统、查电池健康、恢复出厂(S-P02)。网络有该型号卡顿抱怨讨论(W-05，待验证，型号真伪待核)。不编造该型号专属结论。

> 验证：空集降级=退到品类，简单直接，正如你口述。

### 用例 6：增改即时生效 = 加词条 + 补倒排索引条目

操作：新增词条 `S-C05`：气调冷库长期存放会弱化苹果原生果香
必须同时做两件事：
1. 词条表加 S-C05；
2. 倒排表补索引条目：`苹果`+S-C05、`存储`+S-C05、`水果`+S-C05。

重跑用例 1：首搜 `苹果` posting 含 S-C05 → 输出"存储"组多一条：气调冷库长期存放弱化原生果香(S-C05)。
> 验证：只加词条不补倒排，则检索不到；两者都做，下次即生效，无训练。这正是你指出的"光有词条无法精准解锁，得在词表加对应索引条目"。

### 用例 7：同义等价类（规则提取产出，非人工表）

输入：为何如今的苹果不如从前好吃
- `如今`/`从前` 无倒排键 → 若规则提取已产等价类 `如今≈现在`、`从前≈以前`，归一后同用例1；但本问时间不作检索键，等价类仅用于属性标注对齐（对齐到 S-C01 的"早年/近年"）。
- 未产等价类 → 如实报"时间词未匹配属性标注"，不硬猜。
输出：同用例1，标注"`如今/从前`经等价类对齐到早年/近年属性标注"。

### 用例 8：矛盾约束降级

输入：2020年苹果的A市B司股价
求交：`苹果`∩`A市`=∅
降级：最细 token 先放 → 放 `苹果` 后 `2020年`∩`A市`∩`B司`∩`股价`={T-2020股价}
输出：问句含"苹果"与"A市B司"，两者无关联词条（记录：放宽`苹果`）。按A市B司2020股价：年均28.7元(T-2020股价)。显式告知矛盾，不强行合并。

---

### 用例 9：动态新词只建索引不编造

输入：C市D司2023年营收
- `C市`/`D司`/`2023年` 无倒排键 → 动态新词可给编号建倒排，但无词条数据不编造。
输出：已识别 C市/D司 为专名并建索引节点，`2023年营收`无词条（不编造）；如需请上传语料。

## 四、逻辑自洽检查

| 检查项 | 结论 |
|---|---|
| 首搜实体 vs 时间不作键 | ✅ 用例1无年份不筛；用例2/3/4显式年份才启用时间筛 |
| 时间筛子规则非悬空 | ✅ 用例2/3/4 实际启用，规则落地 |
| 多对多 | ✅ 苹果挂20+条，S-A03被3关键词索引 |
| 用度筛 | ✅ 打蜡取食品组，S-W05/W06不选 |
| S/W分层不混引 | ✅ W 均标"待验证" |
| 空集降级=按品类 | ✅ 用例5 华为B8888→手机 |
| 增改=词条+倒排索引 | ✅ 用例6 两者都做，缺一检索不到 |
| 多约束唯一落点 | ✅ 用例2 A市B司2014年 |
| 溯源不编造 | ✅ 全用例挂ID，用例5/8/9 显式不编造 |

结论：逻辑自洽。 唯一注意：时间词在用例1不启用、用例2/3/4启用，靠"问句是否显式给年份"区分，规则一致不矛盾。
