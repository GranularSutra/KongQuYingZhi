## 第一段

**句子1**：“斗之力，三段！”
- “斗之力” → 识别结构“xx之xx” → 名词短语 → 名词
- “三段” → 数量+量词堆叠 → 名词
- 识别句型，套用框架“英语八级/泰拳九段”
{
【识别规则】：
  条件1：X = 名词性实体（能力/属性/水平）
  条件2：Y = 数词 + 量词（等级/段位）
  匹配 → 直接套框架 → 无需再解析内部句法
}


**句子2**：望着测验魔石碑上面闪亮得甚至有些刺眼的五个大字，少年面无表情，唇角有着一抹自嘲，紧握的手掌，因为大力，而导致略微尖锐的指甲深深的刺进了掌心之中，带来一阵阵钻心的疼痛……

- **句型**：复句（连贯复句 + 因果复句）

- **分句1**：望着测验魔石碑上面闪亮得甚至有些刺眼的五个大字
  - “望着” → 动词+进行标识 → 动词，谓语
  - “测验魔石碑上面闪亮得甚至有些刺眼的五个大字” → 名词短语，作宾语
    - “测验魔石碑上面” → “xx上面” → 方位短语 → 名词
    - “闪亮得甚至有些刺眼” → 动词/形容词 + “得” + 程度/结果 → **补语结构**，作定语
      - “闪亮” → 形容词/动词 → 核心
      - “得” → 补语标记
      - “甚至有些刺眼” → 程度补语
    - “的” → 定中标记（左边所有内容作限定，右边“五个大字”作核心）
    - “五个” → 数量短语 → 名词（堆叠）
    - “大字” → 名词，核心
  - 完整结构：sb（隐藏主语=少年） 望着 [xxx 五个大字]

- **分句2**：少年面无表情
  - “少年” → 名词，主语
  - “面无表情” → “面”名词 + “无”动词 + “表情”名词 → 主谓宾完整 → 动词性短语，作谓语（整体归约 → 名词性状态描述）
  - 或识别为成语化结构：n+n → 独立成谓

- **分句3**：唇角有着一抹自嘲
  - “唇角” → 名词，主语
  - “有着” → 动词+进行态 → 动词，谓语
  - “一抹自嘲” → 数量短语 + 动词名词化（“自嘲”动→名） → 名词堆叠 → 宾语
    - “一抹” → 数量 → 名词
    - “自嘲” → 动词名词化 → 名词，核心

- **分句4**：紧握的手掌，因为大力，而导致略微尖锐的指甲深深的刺进了掌心之中
  - “紧握的手掌” → “紧握”动词 + “的”定中标记 + “手掌”名词 → 名词短语，作主语（话题）
  - “因为大力” → “因为”连词/介词 + “大力”名词 → 原因状语
  - “而导致” → “因...而...”因果结构 → “而”连词 + “导致”动词，谓语
  - “略微尖锐的指甲” → “略微”副词 + “尖锐”形容词 + “的”定中标记 + “指甲”名词 → 名词短语，作“导致”的宾语（同时作后面分句的主语，兼语结构）
  - “深深的” → 形容词 + “的/地”，后接“刺进了”（动词）→ **状中标记** → 作状语，扔掉“的”
  - “刺进了” → 动词 + 趋向补语 + 完成时 → 动词，谓语
  - “掌心之中” → “xx之xx” → 方位名词短语，作补语（处所）

- **分句5**：带来一阵阵钻心的疼痛
  - “带来” → 动词，谓语
  - “一阵阵钻心的疼痛” → 名词短语，作宾语
    - “一阵阵” → 数量堆叠 → 名词（定语）
    - “钻心的” → “钻心”动宾结构 + “的”定中标记 → 作定语
    - “疼痛” → 名词，核心


## 第二段

**句子**：“萧炎，斗之力，三段！级别：低级！”测验魔石碑之旁，一位中年男子，看了一眼碑上所显示出来的信息，语气漠然的将之公布了出来……

- **句型**：复句（承接复句）

- **分句1**：“萧炎，斗之力，三段！级别：低级！”
  - 直接引语，作“公布”的宾语内容
  - “萧炎” → 名词
  - “斗之力” → “xx之xx” → 名词
  - “三段” → 数量堆叠 → 名词
  - “级别” → 名词
  - “低级” → 名词（作名词性谓语）

- **分句2**：测验魔石碑之旁，一位中年男子
  - “测验魔石碑之旁” → “xx之xx” → 方位名词短语，作处所状语
  - “一位中年男子” → 数量 + 名词堆叠 → 名词短语，作主语
    - “一位” → 数量 → 名词
    - “中年” → 名词/形容词 → 定语
    - “男子” → 名词，核心

- **分句3**：看了一眼碑上所显示出来的信息
  - “看了” → 动词 + 完成时 → 动词，谓语
  - “一眼” → 数量短语 → 补语（补量）
  - “碑上所显示出来的信息” → 名词短语，作宾语
    - “碑上” → 方位名词
    - “所显示出来的” → “所”字结构 + “的”定中标记 → 作定语
    - “信息” → 名词，核心

- **分句4**：语气漠然的将之公布了出来
  - “语气漠然的” → “语气”名词 + “漠然”形容词 + “的/地”，后接“将之公布了出来”（动词短语）→ **状中标记** → 作状语（扔掉“的”），修饰“公布”，隐藏主语=中年男子
  - “将之” → “将”介词 + “之”代词 → 介词短语，作对象状语
  - “公布了出来” → 动词 + 趋向补语 + 完成时 → 动词，谓语


## 第三段

- **句型**：复句（顺承/条件复句）

- **分句1**：中年男子话刚刚脱口

  - “话” → 名词，主语
  - “刚刚” → 时间副词 → 状语
  - “脱口” → 动宾结构作动词 → 谓语

- **分句2**：便是不出意外的在人头汹涌的广场上带起了一阵嘲讽的骚动
  - “便是” → 副词 + 判断动词 → 表强调承接
  - “不出意外的” → “不出意外”动宾短语 + “的/地”，后接“在...带起了”（动词短语）→ **状中标记** → 作状语（扔掉“的”）
  - “在人头汹涌的广场上” → 介词 + 方位名词短语 → 处所状语
    - “人头汹涌” → 主谓结构 → 作定语
    - “广场上” → 方位名词
  - “带起了” → 动词 + 趋向补语 + 完成时 → 谓语
  - “一阵嘲讽的骚动” → 数量 + 名词堆叠 → 宾语
    - “一阵” → 数量 → 名词（定语）
    - “嘲讽的” → 名词 + “的”定中标记 → 作定语
    - “骚动” → 名词，核心


## 第四段

**句1**：“三段？嘿嘿，果然不出我所料，这个‘天才’这一年又是在原地踏步！”

- “三段？” → 名词 + 问号，独立问句
- “嘿嘿” → 拟声词/叹词，独立语
- “果然不出我所料” → “果然”情态副词 + “不出”动词+否定 + “我所料”（“我”代词 + “的”定中标记 + “料”动词名词化 → “我的预料”） → 动宾结构，作插入语
- “这个‘天才’” → 指示代词 + 名词 → 主语
- “这一年” → 指示代词 + 时间名词 → 时间状语
- “又是” → “又”表次数 + “是”动词 → 谓语（强调判断）
- “在原地踏步” → 介词 + 方位名词 + 动宾 → 动词性谓语

**句2**：“哎，这废物真是把家族的脸都给丢光了。”

- “哎” → 叹词，独立语
- “这废物” → 指示代词 + 名词 → 主语
- “真是” → 副词 + 判断动词 → 谓语（强调）
- “把家族的脸” → “把”介词 + “家族的脸”（“家族”名词 + “的”定中标记 + “脸”名词） → 介词短语，作对象状语
- “都” → 范围副词 → 状语
- “给” → 口语废词（无实义）
- “丢光了” → 动词 + 结果补语 + 完成时 → 谓语

**句3**：“要不是族长是他的父亲，这种废物，早就被驱赶出家族，任其自生自灭了，哪还有机会待在家族中白吃白喝。”

- **分句1**：要不是族长是他的父亲
  - “要不是” → 连词，表假设条件
  - “族长” → 名词，主语
  - “是他的父亲” → “是”判断动词 + “他的父亲”（“他”代词 + “的”定中标记 + “父亲”名词） → 动宾结构，作谓语

- **分句2**：这种废物，早就被驱赶出家族
  - “这种废物” → 指示代词 + 名词 → 主语（话题）
  - “早就” → 时间副词 → 状语
  - “被驱赶出” → “被”介词 + “驱赶”动词 + “出”趋向补语 → 动词短语，谓语
  - “家族” → 名词，补语（处所）

- **分句3**：任其自生自灭了
  - “任” → 动词，谓语
  - “其” → 代词，宾语
  - “自生自灭” → 并列动词短语 → 宾语补足语
  - “了” → 完成时标记

- **分句4**：哪还有机会待在家族中白吃白喝
  - “哪” → 疑问代词 → 状语（表反问）
  - “还有” → 动词，谓语
  - “机会” → 名词，宾语
  - “待在家族中” → “待”动词 + “在”介词 + “家族中”方位名词 → 动词短语，作“机会”的定语/补语
  - “白吃白喝” → 并列动词短语 → 目的补语

**句4**：“唉，昔年那名闻乌坦城的天才少年，如今怎么落魄成这般模样了啊？”

- “唉” → 叹词，独立语
- “昔年那名闻乌坦城的天才少年” → 名词堆叠，主语
  - “昔年” → 时间名词 → 定语
  - “那” → 指示代词 → 定语
  - “名闻乌坦城” → 主谓结构（“名”名词 + “闻”动词 + “乌坦城”名词）→ 作定语
  - “的” → 定中标记
  - “天才少年” → “天才”名词 + “少年”名词 → 核心（“少年”为最终核心）
- “如今” → 时间名词 → 状语
- “怎么” → 疑问副词 → 状语
- “落魄成” → 动词 + 补语 → 谓语
- “这般模样” → 指示代词 + 名词 → 补语
- “了啊” → 语气助词堆叠

**句5**：“谁知道呢，或许做了什么亏心事，惹得神灵降怒了吧……”

- **分句1**：谁知道呢
  - “谁” → 疑问代词，主语

- **分句2**：或许做了什么亏心事

  - “做了” → 动词 + 完成时 → 谓语
  - “什么亏心事” → 疑问代词 + 名词堆叠 → 宾语
    - “什么” → 疑问代词，定语
    - “亏心” → 动宾结构作定语
    - “事” → 名词，核心

- **分句3**：惹得神灵降怒了吧
  - “惹得” → 动词 + 补语标记 → 谓语
  - “神灵降怒” → 主谓结构（“神灵”名词 + “降怒”动宾）→ 作补语（结果/对象）
  - “了吧” → 语气助词堆叠


## 第五段

- **分句1**：周围传来的不屑嘲笑以及惋惜轻叹

    - “不屑嘲笑” → “不屑”形容词/动词 + “嘲笑”名词 → “不屑的嘲笑”省略“的”
    - “以及”连词
    - “惋惜轻叹” → “惋惜”动词作定语 + “轻叹”名词
  - 整体 → 名词短语，作主语

- **分句2**：落在那如木桩待在原地的少年耳中
  - “落在” → 动词 + 补语 → 谓语
  - “那如木桩待在原地的少年耳中” → 指示代词 + 名词堆叠 + 方位名词 → 名词，作补语/宾语（处所）
    - “那” → 指示代词，定语
    - “如木桩待在原地的” → “如”动词（比喻）+ “木桩”名词 + “待在原地”动宾短语 + “的”定中标记 → 整体作定语
    - “少年” → 名词，核心
    - “耳中” → 方位名词，处所补语

- **分句3**：恍如一根根利刺狠狠的扎在心脏一般
  - “恍如” → 动词（比喻），谓语
  - “一根根利刺” → 数量堆叠 + 名词 → 名词，作宾语
  - “狠狠的” → 形容词 + “的/地”，后接“扎在”（动词）→ **状中标记** → 作状语（扔掉“的/地”）
  - “扎在” → 动词 + 补语 → 谓语
  - “心脏” → 名词，补语（处所）
  - “一般” → 助词，比喻标记

- **分句4**：让得少年呼吸微微急促
  - “让得” → 动词 + 补语标记 → 动词（致使义），谓语
  - “少年” → 名词，宾语
  - “呼吸微微急促” → 主谓结构，作宾语补足语
    - “呼吸” → 动词/名词 → 主语
    - “微微” → 副词 → 状语
    - “急促” → 形容词 → 谓语

## 第七段

**句子**：“这些人，都如此刻薄势力吗？或许是因为三年前他们曾经在自己面前露出过最谦卑的笑容，所以，如今想要讨还回去吧……”

- **问句**：这些人，都如此刻薄势力吗？
  - “这些人” → 指示代词 + 名词 → 名词主语（话题）
  - “都” → 范围副词 → 状语
  - “如此” → 程度副词 → 状语
  - “刻薄势力” → 形容词并列 → 谓语
  - “吗” → 疑问语气助词

- **解释分句1**：或许是因为三年前他们曾经在自己面前露出过最谦卑的笑容
  - “或许是因为” → 副词 + 判断动词“是” + 连词“因为” → 表推测原因
  - “三年前” → 时间名词 → 状语
  - “他们” → 代词，主语
  - “曾经” → 时间副词 → 状语
  - “在自己面前” → 介词 + 方位名词短语 → 处所状语
    - “自己”代词 + “面前”方位名词
  - “露出过” → 动词 + 完成时 → 谓语
  - “最谦卑的笑容” → 副词 + 形容词 + “的”定中标记 + 名词 → 名词宾语
    - “最谦卑的” → 副词 + 形容词 + “的” → 作定语
    - “笑容” → 名词，核心

- **解释分句2**：所以，如今想要讨还回去吧
  - “所以” → 连词，表结果
  - “如今” → 时间名词 → 状语
  - “想要” → 动词（愿望着），谓语
  - “讨还回去” → 动词 + 趋向补语堆叠 → 动词短语，作宾语
  - “吧” → 语气助词，表揣测


## 第八段

**句子**：苦涩的一笑，萧炎落寞的转身，安静的回到了队伍的最后一排，孤单的身影，与周围的世界，有些格格不入。

- **分句1**：苦涩的一笑
  - “苦涩的” → 形容词 + “的”定中标记 → 作定语
  - “一笑” → 数量短语（“一”数词 + “笑”动量词/名词）→ 名词，作谓语（独立表动作）

- **分句2**：萧炎落寞的转身
  - “萧炎” → 名词，主语
  - “落寞的” → 形容词 + “的/地”，后接“转身”（动词）→ **状中标记** → 作状语（扔掉“的/地”）
  - “转身” → 动词，谓语

- **分句3**：安静的回到了队伍的最后一排
  - “安静的” → 形容词 + “的/地”，后接“回到了”（动词）→ **状中标记** → 作状语（扔掉“的/地”）
  - “回到了” → 动词 + 趋向补语 + 完成时 → 谓语
  - “队伍的最后一排” → 名词堆叠 + 方位名词 → 名词，作处所补语/宾语
    - “队伍的” → 名词 + “的”定中标记 → 定语
    - “最后” → 形容词 → 定语
    - “一排” → 数量短语 → 核心

- **分句4**：孤单的身影，与周围的世界，有些格格不入
  - “孤单的身影” → 形容词 + “的”定中标记 + 名词 → 名词主语（话题）
  - “与周围的世界” → 介词 + 名词短语（“周围”名 + “的”定中标记 + “世界”名）→ 比较状语
  - “有些” → 程度副词 → 状语
  - “格格不入” → 成语/形容词短语 → 谓语


## 第九段

**句子**：“下一个，萧媚！”

- **句型**：非主谓句（名词性呼告句）
- “下一个” → 数量短语（“下”方位词 + “一个”数量）→ 名词，作呼语/话题
- “萧媚” → 名词，作呼语/称呼谓语


## 规则小结

| 标记 | 功能 | 处理方式 |
|---|---|---|
| **的** | 定中标记 | 左边限定 → 名词，右边核心 → 名词；整体名词化 |
| **地/的（状中）** | 状中标记 | 修饰语 + 动词，扔掉“的/地”，作状语 |
| **得** | 补语标记 | 动词/形容词 + 得 + 程度/结果/对象，作补语 |
| **代词+的+名词** | 名词性短语 | 按定中处理 |
| **隐藏主语** | 承前省略 | 按上下文补出（通常为前一分句主语） |
| **名词堆叠** | 多个名词连用 | 最后一个为核心，前面均为定语 |
| **xx之xx** | 结构识别 | 整体归为名词性短语 |
| **“给”** | 口语废词 | 无实义，标注后忽略 |
| **因xx而xx** | 因果结构 | 整体作谓语或状语 |
