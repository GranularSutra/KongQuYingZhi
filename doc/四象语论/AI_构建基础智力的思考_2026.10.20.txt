# 基础智力构建方案

## 一、目标

构建一个**可运行、可校验、可扩展**的基础智力底座，服务文字 AI。

规模基准：

```text
小学三年级水平
1500~2000 常用字
3000~5000 常用词
几百条模式
不到 100 种常用句型
```

范围：

```text
语文 + 科学（原自然课）
```

不包含：

```text
复杂数学计算
古文生僻字
专业领域知识
各国历史
```

---

## 二、构建顺序

```text
第一步：定词表
第二步：定模式表
第三步：定句型骨架
第四步：建检索表
第五步：建常识条目
第六步：跑通最小闭环
第七步：校验与扩展
```

---

## 三、第一步：定词表

### 1. 字表

```text
主表：1500~2000 常用字（小学三年级水平）
扩展：3500 常用字（后续）
生僻字：不进主表，走未知字符表
```

### 2. 词表

```text
高频名词：几百个（人、手、水、饭、家、路、车、钱……）
高频动词：几百个（拿、给、吃、走、看、说、推、拉……）
高频形容词：几百个（大、小、好、坏、快、慢、冷、热……）
方位/时间/数量词：几十个
功能词/虚词：几十个
```

### 3. 词表原则

```text
同类词一个处理：高兴/开心/快乐 → 主表留“高兴”
音译词用英文原词：sofa、coffee、logic
专名中英混用：iPhone、Python
生僻字不进主表
```

规模：

```text
3000~5000 词条
```

---

## 四、第二步：定模式表

基础智力不是背词，是内化模式。  
模式表是核心。

### 1. 指代对应

```text
词 → 实体
我、你、他、妈妈、手、水、饭、家
```

### 2. 交互模式

```text
谁 对 谁 做什么
拿、给、吃、走、看、说、推、拉、打、抱
```

### 3. 因果模式

```text
A 导致 B
火 → 烫
雨 → 湿
饿 → 哭
摔 → 疼
病 → 弱
```

### 4. 空间模式

```text
A 在 B
A 向 B
A 从 B 来
上/下、里/外、前/后、来/去、近/远
```

### 5. 时间模式

```text
A 在 B 之前/之后
A 持续 B
先/后、现在/以后、白天/晚上、快/慢
```

### 6. 数量与比较

```text
A 比 B 多/少/大/小
多/少、大/小、一个/两个、够/不够
```

### 7. 社会交互

```text
谁 对 谁 做什么
给/拿、问/答、叫/应、要/给、好/坏
```

### 8. 情绪与评价

```text
A 是 好/坏/对/错
A 让 谁 高兴/疼/怕
疼/舒服、怕/不怕、好/坏、对/错
```

规模：

```text
几百条模式
```

---

## 五、第三步：定句型骨架

常用句型不到 100 种。  
先定最核心的几十种。

### 1. 基本骨架

```text
N V N       我 爱 你
N V         我 走
N A         花 红
N 是 N      我 是 学生
N 在 N      我 在 家
N 有 N      我 有 书
```

### 2. 补充骨架

```text
时间 + N V N
空间 + N V N
N V N + 补充
N V + 补充
```

### 3. 逻辑骨架

```text
因为 A，所以 B
如果 A，就 B
A 但是 B
A 而且 B
```

### 4. 嵌套骨架

```text
简单句 + 简单句
X 的 Y
```

规模：

```text
先定 30~50 种核心骨架
后续扩展到不到 100 种
```

---

## 六、第四步：建检索表

### 1. 结构

```text
检索表：关键词 → 条目序号列表
```

### 2. 关键词来源

```text
词表里的词
常识条目描述里的词
模式表里的标记词
```

### 3. 建表方式

```text
每个词条抽出关键词
→ 追加到检索表
→ 关键词 → [条目序号]
```

例子：

```text
条目 1：苹果（水果）
关键词：苹果、水果、仁果类、有皮、有核、果肉脆、可食用、味甜

检索表：
苹果 → [1]
水果 → [1]
仁果类 → [1]
有皮 → [1]
有核 → [1]
果肉脆 → [1]
可食用 → [1]
味甜 → [1]
```

---

## 七、第五步：建常识条目

### 1. 条目结构

```text
序号
关键词
义项
上一级
分类路径
描述句
特征
关联
来源/置信度
```

### 2. 条目类型

```text
百科型：苹果、水、火、家、学校
因果型：火→烫、雨→湿、饿→哭
交互型：给、拿、吃、走
空间型：上/下、里/外
时间型：先/后、白天/晚上
数量型：多/少、大/小
社会型：问/答、叫/应
情绪型：高兴、疼、怕
```

### 3. 规模

```text
先建 1000~3000 条核心条目
后续扩展到 1~3 万条
```

---

## 八、第六步：跑通最小闭环

### 1. 输入

```text
我在家吃饭。
```

### 2. 处理

```text
切分：我 / 在 / 家 / 吃饭
标注：我(N) 在(V) 家(N) 吃饭(V)
五维：我=实体，在=空间，家=空间/实体，吃饭=交互
结构：N V N V
```

### 3. 检索

```text
我 → 条目
在 → 空间模式
家 → 条目
吃饭 → 交互模式
```

### 4. 输出

```text
结构：谁 在 哪 做什么
可生成：他在家吃饭、我在学校吃饭、我在家看书
```

---

## 九、第七步：校验与扩展

### 1. 校验

```text
字面可核对
结构可追溯
关系可标注
错了能定位到词表/模式表/句型骨架
```

### 2. 扩展

```text
词表：3000~5000 → 8000~10000
模式表：几百条 → 上千条
句型骨架：30~50 → 不到 100
常识条目：1000~3000 → 1~3 万
```

### 3. 原则

```text
先跑通最小闭环
再扩展覆盖
不追求一次全覆盖
不引入大模型
不引入矩阵
```

## 十、最小构建清单

```text
1. 字表：1500~2000 常用字
2. 词表：3000~5000 词条
3. 模式表：几百条（指代、交互、因果、空间、时间、数量、社会、情绪）
4. 句型骨架：30~50 种核心骨架
5. 检索表：关键词 → 条目序号
6. 常识条目：1000~3000 条核心条目
7. 最小闭环：输入 → 切分 → 标注 → 检索 → 输出
8. 校验规则：字面可核对、结构可追溯、关系可标注
```

---

## 十一、一句话总结

**构建基础智力，按七步走：定词表（1500~2000 字 + 3000~5000 词）、定模式表（几百条）、定句型骨架（30~50 种）、建检索表（关键词→序号）、建常识条目（1000~3000 条）、跑通最小闭环（输入→切分→标注→检索→输出）、校验与扩展。规模按小学三年级水平，范围按语文+科学，不引入大模型，不引入矩阵。**
