第一，拿后世印欧语框架（主谓宾定状补这套舶来模板）硬套古文，强行给《论语》之类古汉语做词性、句法标注，大量标注不是 “有分歧”，是	错配	；
第二，人脑是低功耗、增量、追加式的处理器，不是编译器那种一次性预编译、树形嵌套的高性能 CPU。不管上古汉语，还是今天的口语，底层组织逻辑是“先抛出指称对象，再追加补充信息”，而不是“预先规划好完整的主谓宾树”。


#### 低功耗追加式口语
古语/口语，是人脑低功耗的表达习惯“主句先落地，后面堆叠追加，而不是嵌套”
	举例 “名词+若干补充”，举例“N+A”
		“国立”“天下平”“肤白、貌美、腿长、腰细、长发飘飘、风姿绰约、海枯石烂”

``` 
- N （单独指称）
- N + A （对象 + 追加特征：肤白）
- N + V （对象 + 追加交互：仁者爱）（我逃）
- N + V + N （对象 + 交互 + 对象：爱人）
```
``` 例句
“我去你家玩”
- 先抛出锚点：我（N）	
- 追加一件事：去你家（V+N）	。到这里，这个事件已经闭环了，大脑已经接住这件事：我去你家。
- 再追加一层补充：	玩（V）。补充说明刚才这件事的意图。
```

```  泛化/理解，规则方案之一
“我在家里读书”，正反两遍，切词得NFNVN
短语词性组合已枚举，条目命中若干，最高概率=N FN VN
深入词元内置使用提醒（大概率空）+ 共现统计 → 通过检查（没命中或不通过检查，就用细分类和词义/句法做兜底推理）
锚点先落地（我），补场景（在家里），再补动作（读书）。 
命中“谁 在哪里 做什么”
```

#### 前置和倒装

直白的道理：“谁前置，就是突出谁”。没有什么隐藏的深层句式、倒装还原。

```
- `天下(N) 平(A)`：N在前。重心落在【天下】这个对象上，讲这个对象是什么状态；
- `平(V) 天下(N)`：V在前。重心落在【平】这个行动上，讲要对这个对象做这件事。
- 贵五谷而贱金玉：V（贵、贱）前置，重心是主张、价值取舍；
- 饭熟了：N（饭）在前，重心是饭，描述它的状态；
- 饭熟了（N起头：说饭怎么样了）
- 吃饭！（V起头：喊你执行这个动作）
```

语序不是“从标准版本改出来的变形”，语序本身就是选择重心的手段：
1. 把N放开头：我先把这个事物拎出来，你们盯着这个东西，我后面补充它的状态、发生的事（陈述、描述，最常见的口语模式，咱们之前说的低功耗追加）；
2. 把V放开头：我先把动作抛出来，重点是这件事要执行、要落实（祈使、号召、纲领，修身、齐家、治国、平天下全是这类）；
3. 语言统计，主语多是名词。

契合人脑流式输出：
你脑子里当下最在意、最先冒出来的那个东西，就先说出来。
心里想着这件事要做 → 先蹦出动词；
心里想着这个东西怎么样了 → 先蹦出名词。
没有额外的移位加工，低功耗，不折腾。

#### 古今杂文

古以单字为主，后世发展出双音词，本质是语音减负、字库减负。

上古汉语，“字≈词”，一个音节对应一个书写符号（字），一个字承载一个词义单元。
文明发展 → 交流需求变细
解决路径 = 分级定位（冗长）或 造字（如果是全新字眼，音和文，记忆负担大、多了就传承困难）
两字组合一个意思（举例，不+正，日+青，十+路）  → 因为纸张贵/字形简单可合并，再造新字，也是门第之别 → 纸张/物产提升，明清民间出现“半百半文”而不是学“万字表/文言文” → 科技爆发，重转词（组合定位），字根（即单字）大幅删减
之 → 的地得（文章清了，但口语中无用，难评）


#### 习惯

`很 + 大`｜`very + big`
- 大：A (a_qual) 【属性刻画】
- 很：A (a_deg) 【程度刻画】
它们是“连续追加刻画”,有些语言会说 “big very”
美极了：美（A 属性）→ 极（A 程度），这是汉语固化习惯，大家已经熟悉这个追加顺序；
极美了：极（A 程度）→ 美（A 属性）→ 阅读中很多时候被大脑自动修正为“美极了”，你可能都没发现不一样

```
简单归类

前置程度：很 / 挺 / 非常 + 特征（很大、很美、非常冷）
后置程度：特征 + 极 / 透 / 死 + 标记（美极了、冷透了、烦死了）

前置模板：[程度词] + [属性]
后置模板：[属性] + [后置程度词] + [了]

```

#### 例外
本就是语种残留、文明交汇产出的大杂烩。
遇到不好解析的，直白点，归类为“固定短语”即可。

#### 其他例子
原句子“其他算力、上下文一致性、幻觉、模拟器适配这些争论，都只是衍生出来的推论。”
``` 标注
其他（N_F） 算力（N）（补充）
上下文（N） 一致性（N）（补充）
幻觉（N）
模拟器（N） 适配（V退化为N）（补充）
这些（N_F）争论（V退化为N）（补充一个小判断）
都（F） 只是（N_F） 衍生（V） 出来（V_F，标记，固定短语）的（F） 推论（V退化为N）。（补充一个大判断）

备注：“衍生出来的推论”，句法命中“X的Y”。
句法辨析（也就几种）：
	他不是你能讨论的（“V+的”，字面含义是“指代/强调，省略受动者”≈“指代占位”）
	我的鞋子（归属关系，‘我’起到限定作用）（由“指代占位”衍生得来，现单录一行）
	你今天买的什么
	他拿的是酱油不是醋
	我的不是你的，分得清？
	我（限定） 打的（强调指代） 天下（补正被指代的本体），你管得着？
	只是（N_F） 衍生出来的（指代） 推论（补正被指代的本体）
```
