### 问答逻辑

#### 第一步：解析问题
```python
输入："苹果是什么颜色的？"
HanLP解析 → 骨架：[苹果] + [是] + [什么颜色]
提取关键词：苹果、颜色
```

#### 第二步：查词典
```python
dict.query("苹果")
→ 返回：{"词义": "蔷薇科苹果属植物的果实", "颜色": "红色、绿色、黄色"}
```

#### 第三步：匹配问答模板
```python
TEMPLATES["问答"] = {
    "什么颜色": "查[物体].颜色属性",
    "是什么": "查[物体].词义",
    "谁": "查[人物].身份",
}
匹配到"什么颜色" → 去词典里取"颜色"字段
```

#### 第四步：输出
```python
"苹果通常是红色、绿色或黄色的。"
```

### 案例"如何评价苹果公司"


#### 第一步：解析问题（拆结构）

```python
输入："如何评价苹果公司？"
HanLP解析 → 骨架：[如何] + [评价] + [苹果公司]
提取关键词：评价、苹果公司（实体）
问题类型判定：评价类问题 → 属于"观点/分析"模板
```

黑板缓存：
```
{
  "问题类型": "评价类",
  "目标实体": "苹果公司",
  "要求动作": "给出评价",
  "容差要求": "中偏高（允许主观表述）"
}
```

#### 第二步：查刚性数据库

```python
# 在刚性语料库中检索"苹果公司"
检索结果：
- 基本信息：Apple Inc.，美国科技公司，1976年创立
- 主营业务：iPhone、Mac、iPad、软件服务
- 关键事实：2023年市值超3万亿美元
```

#### 第三步：查词典/知识库

```python
# 萌典中查"苹果公司"（如果有收录）
# 如果没有，查维基百科离线版或挂载的百科知识库
补充信息：
- 创始人：乔布斯、沃兹尼亚克
- 定位：消费电子、软件服务
- 标志性产品：iPhone（2007）、App Store（2008）
```

#### 第四步：匹配评价模板

```python
TEMPLATES["评价类"] = {
    "结构": ["背景", "正面评价", "负面评价", "总结"],
    "槽位": {
        "背景": "{实体}成立于{年份}，总部位于{地点}",
        "正面评价": "在{领域}方面表现出色，{具体优点}",
        "负面评价": "也存在{问题/争议}",
        "总结": "总体而言，{综合判断}"
    }
}
```

#### 第五步：生成输出

```python
输出：
"苹果公司（Apple Inc.）是美国一家科技企业，由乔布斯等人于1976年创立。
该公司在消费电子产品设计和生态系统整合方面表现出色，iPhone、Mac等产品具有较高市场影响力。
同时，其封闭生态和产品定价策略也引发过一些讨论。
总体而言，苹果公司是科技行业的重要参与者之一。"
```
