# 空曲映智
**白盒多模态体系 · 句子级推理 · 文字链路无矩阵运算 · 脱离Transformer范式**

## 核心立论
语言智能的本质是结构（句法、因果、时空逻辑）的识别复用，而非词频统计拟合。
以《四象语论》为语法基座，理论适配全部人类语种；统一文字、图像、语音、视频的底层认知框架。

## 设计目标
- CPU单句生成＜50ms
- 语料压缩比＞100
- 硬件：消费级PC（AMD 3900X + Arc B580）
- 无上下文窗口限制，数据库持久化召回
- 硬件开销为Transformer路线0.1~0.3倍，训练开销＜0.001倍

## 范式对比
| 维度 | Transformer | 空曲映智 |
|---|---|---|
| 推理单元 | Token | **句子** |
| 知识载体 | 权重矩阵（黑盒） | 标签库、枚举库（白盒）+高压缩结构化原文库 |
| 上下文 | 窗口截断 | **数据库检索** |
| 训练 | GPU集群，多周训练 | 单机单次遍历 |
| 逻辑来源 | 统计涌现 | **原生因果、逻辑、语法模板** |
| 多模态 | 独立编码器拼接 | **四象结构同构映射** |

## 核心组件
- 双层统计：结构层 / 词频层
- 认知、遗忘、时空、传播引擎
- 标签索引 + 分层检索（B+Tree / HNSW）
- 枚举库：因果、逻辑、《四象语论》语法模板
- 多模态映射层：图文音视频转为四象结构
